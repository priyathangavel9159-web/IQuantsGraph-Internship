Task 1 – Revenue Analysis and Visualization

Project Description
This task analyzes revenue data using Python. It calculates the total revenue from the specified revenue categories and displays the revenue distribution through a bar chart using Matplotlib.

Technologies Used
- Python
- Matplotlib
- pathlib
- Matplotlib.ticker

Features
- Stores revenue information using a Python dictionary.
- Filters revenue entries using keys starting with `Rev`.
- Calculates the total revenue.
- Uses the `get_rev_name()` function to identify revenue categories.
- Displays revenue values with three decimal places.
- Generates and saves a bar chart as `revenue_plot.png`.

Installation
Install Matplotlib using:
    pip install matplotlib


How to Run
1. Open the task1-revenue folder in VS Code.
2. Open the terminal.
3. Run the following command:
    python revenue.py

Expected Output
- Displays individual revenue categories and their values.
- Displays the total revenue.
- Generates the revenue bar chart.

Output File
`revenue_plot.png`

Project Files
- `revenue.py` – Python source code.
- `revenue_plot.png` – Generated revenue visualization.
- `README.md` – Project documentation.

Conclusion
This task demonstrates how Python dictionaries, functions, filtering and Matplotlib can be used for revenue analysis and visualization.
