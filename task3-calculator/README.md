Task 3 – Office Commute Calculator

Project Description
This task develops a Python-based office commute calculator. It calculates daily and total travel and meal expenses based on the number of working days. It also checks whether the available card balance and wallet cash are sufficient to cover the expenses.

Technologies Used
- Python
- datetime
- timedelta

Features
- Accepts the user's name and financial details.
- Accepts card balance and wallet cash.
- Calculates daily meal and travel expenses.
- Calculates total expenses based on the number of working days.
- Displays the remaining card and wallet balances.
- Identifies insufficient balances and displays the shortage amount.
- Validates numeric inputs and positive working days.
- Validates the date format (dd/mm/yyyy).
- Calculates the office schedule's end date.

How to Run
1. Open the task3-calculator folder in VS Code.
2. Open the terminal.
3. Run the following command:
      python calculator.py
4. Enter the requested details when prompted.

Sample Input

Name: riya
Card balance: 1000
Wallet cash: 500
Meal cost: 100
One-way travel cost: 50
Working days: 5
Start date: 05/11/2026


Expected Results
- Total travel cost: Rs. 250.00
- Total meal cost: Rs. 500.00
- Remaining card balance: Rs. 750.00
- Remaining wallet balance: Rs. 0.00
- Start date: 05/11/2026
- End date: 09/11/2026
